A report system for the Instituto Angelitos Alegres

## TechStack
* Next.js
* Tailwind
* Shadcn
* Prisma
* Postgres

## ⚠️ Nota de Seguridad

**NO HABILITAR tareas automáticas de VS Code** (`task.allowAutomaticTasks`) ni configurar tareas con `runOn: "folderOpen"`. Este repositorio fue previamente comprometido con malware que se ejecutaba automáticamente al abrir la carpeta. Siempre revisar cambios en `.vscode/` cuidadosamente.
